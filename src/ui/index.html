La file est vide

Tout ce qui a été ajouté a été lancé. Une tâche quitte la file dès qu'elle démarre ; son résultat part ensuite dans l'historique.

Limite connue : le moteur n'a pas encore d'interruption coopérative, donc une tâche en cours ne peut pas être mise en pause depuis l'interface (décision D-084). Seules les tâches en attente peuvent être retirées. Un téléchargement interrompu par l'arrêt du processus reprend au lancement suivant grâce au fichier .part.

Aucune aspiration

Une aspiration parcourt un site, en retient les fichiers puis les télécharge dans un dossier propre à cette aspiration. Rien n'est suivi hors du domaine de départ.

Chaque aspiration écrit sa file et son projet dans son propre dossier. Elle peut ensuite être contrôlée depuis l'écran Vérification. Le respect de robots.txt n'est pas réglable : décision D-004.
